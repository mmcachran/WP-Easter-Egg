# WP Easter Egg

Welcome to the WP Easter Egg wiki! This plugin allows you to add fun Easter Eggs to your WordPress site using the Konami code or a custom key sequence.

## Features

* **Multiple Actions**: Rotate screen, Cornify, Raptorize, Move image, Custom JS
* **Flexible Key Sequences**: Use the classic Konami code or define your own
* **Filter System**: Control which posts display the Easter Egg (off, exclusive, inclusive)
* **Keycode Helper**: Visual helper for entering custom key codes in the admin
* **Media Library Integration**: Upload images directly from the settings page

## Quick Start

1. Install and activate the plugin
2. Go to Settings > WP Easter Egg
3. Choose your Easter Egg action and key sequence
4. Save your settings
5. Visit your site and enter the key sequence to trigger the Easter Egg
